## Founding Author

**MSymbios** ([@MSymbios](https://github.com/MSymbios)) — *Heria Zone*

Designed and built HZLib from the ground up. All initial systems:
- Multi-loader entity framework (`NativeEntity`, `NativeEntityFamily<T>`)
- Feature composition system (`EntityFeature`, `withFeature`)
- Variant system (`TextureVariantFeature`, `ModelVariantFeature`, `SizeVariantFeature`)
- Appearance system (`ConditionalAppearanceFeature`, `CompositeAppearanceFeature`)
- Animation Profile System (`AnimationProfile`, `AnimationPool`, `IdleSlot`, `BoneVisibilityFeature`)
- NBT Data Pipeline (`DataCompound`, `DataField<T>`, `EntityDataSchema`, `MigrationChain`)
- Platform services (`IPlatformServices`, `Services`)
- Rendering layer (`NativeModel`, `NativeAnimation`, `NativeRenderer`, `LayerRenderPipeline`)
